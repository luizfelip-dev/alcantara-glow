# Studio em Dia — V2

Esta versão está em desenvolvimento separado. A aplicação publicada continua usando a branch `main` e não recebe estas alterações até a conclusão e aprovação da V2.

## Ordem de entrega

1. Clientes e vínculo com atendimentos
2. Agenda, horário e status do atendimento
3. Sinal, pagamentos parciais e valores pendentes
4. Adicionar evento à agenda do celular
5. Confirmação pelo WhatsApp
6. Metas, relatórios, exportação, backup e notificações

## Primeira etapa

- Cadastro de cliente com nome, telefone e observações
- Edição e exclusão de cliente sem apagar atendimentos anteriores
- Histórico resumido por cliente
- Seleção de uma cliente cadastrada ao criar um atendimento
- Seleção de um ou mais serviços, sem cadastro separado de combos
- Valor do atendimento definido livremente
- Isolamento dos dados por usuário com Row Level Security

## Publicação segura

A migração do banco só será aplicada quando a etapa estiver pronta para teste. Antes do lançamento final serão feitos backup, validação das políticas de segurança, teste em celular e computador e verificação de preservação dos dados existentes.
